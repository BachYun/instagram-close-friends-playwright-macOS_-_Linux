# Security

This beta has no guaranteed security support period. Review the code and dependencies
before using it with any important account. Do not treat a private repository as a safe
place for authentication state.

Never submit passwords, Authy/TOTP seeds or codes, browser profiles, cookies, account
exports, actual follower lists, raw responses or unredacted screenshots in a public issue.
The error log is deliberately minimal; review even sanitized output before sharing it.

For a suspected vulnerability, use GitHub's private vulnerability-reporting interface
if enabled for this repository. If no private reporting channel is configured, create a
non-sensitive issue requesting a secure channel without disclosing exploit details or
credentials. No maintainer email or guaranteed response time is asserted by this template.

If a secret was exposed, revoke/rotate it at its provider first. Deleting it from the
working tree or adding `.gitignore` does not remove earlier Git history or invalidate a
credential. Review the entire repository history before changing visibility.

See docs/SAFETY.md for browser-control risks and the limitations of the publication checker.
